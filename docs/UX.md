# Expérience utilisateur

## Bibliothèque

- ✅ La présentation retenue est une liste simple, sans cartes artistes.
- ✅ Les informations de qualité audio et le nombre de titres doivent être visibles.
- ⚪ Exemple de libellé de qualité : `FLAC · 24/192`.
- ⚪ Les parcours de navigation et de lecture complets restent à concevoir et implémenter.

## Administration

- ⚪ Prévoir des parcours pour importer et gérer les fichiers, résoudre les conflits, actualiser la bibliothèque et corriger les tags (détails dans [LIBRARY.md](LIBRARY.md)).

La simplicité de la liste constitue la décision UX validée ; aucun écran non implémenté n'est décrit ici comme existant.
